# POODIN Editing Guide

## Brand
Edit brand information in:
`src/config/brand.ts`

## Homepage
Edit hero, sections and marketing content in:
`src/config/home.ts`

## Theme
Edit global visual tokens:
`src/config/theme.ts`

## Products
Products are separated from UI. Later WooCommerce API will replace the local catalog.

## Design principle
Components should consume configuration and data instead of containing hardcoded brand content.
